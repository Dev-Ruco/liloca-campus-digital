# Liloca Campus Digital

Plataforma independente de cursos de curta duração, pensada para Moçambique.

Este repositório foi separado do site artístico da Liloca. O projecto `liloca-artist-hub` permanece reservado ao site da cantora.

## Estrutura
- React + TypeScript + Vite
- Mobile-first
- Catálogo de cursos
- Inscrição pessoal e institucional
- Área de estudo com vídeo, materiais e perguntas interactivas
